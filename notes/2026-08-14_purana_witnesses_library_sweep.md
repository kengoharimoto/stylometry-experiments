## The dated witnesses, in rough order

| witness | usage |
|---|---|
| Patañjali, Mahābhāṣya (Paspaśā) | **singular**: "vākovākyam itihāsaḥ purāṇam vaidyakam" — one purāṇa among the branches of verbal lore |
| Kauṭilya, Arthaśāstra 1.5.14 | **singular**, a *component* of itihāsa: "purāṇam itivṛttam ākhyāyikodāharaṇaṃ dharmaśāstram arthaśāstraṃ cetīhāsaḥ" |
| Manu 3.232 | **plural**: "ākhyānānītihāsāṃś ca purāṇāni khilāni ca" (śrāddha recitation list) — earliest plural in a dated text |
| Yājñavalkya | both: 1.3 purāṇa as vidyāsthāna and 1.45 "vākovākyam purāṇaṃ ca" (**singular**); 1.101, 3.189 purāṇāni (**plural**) |
| Viṣṇusmṛti 30.38 | study-list compound purāṇa-itihāsa-... |
| Aśvaghoṣa, Kālidāsa | no genre reference at all (only false positives / adjectival "ancient") |
| Amarakośa 1.6.361 | "ākhyāyikopalabdhārthā **purāṇaṃ pañcalakṣaṇam**" — singular, with the five-characteristics definition, canonized in the lexicon |
| Rājaśekhara, Kāvyamīmāṃsā (~900) | "tadidaṃ **vāyuproktapurāṇādibhya** upalabdham" — the Vāyuprokta-purāṇa cited as doctrinal source |
| Vācaspatimiśra, Tattvavaiśāradī (~950) | twice quotes verses as "**vāyuproktam**" (scriptural authority in yoga context) |
| Inscriptions (7_inscriptions) | only purāṇapuruṣa epithets; a medieval Munirabad fee for reciting the "Śivadharmapurāṇa" |

## Refinements to the corpus-internal synthesis

1. **Plural genre-awareness is older than the purāṇic evidence alone
   suggested**: already in Manu 3.232 (recitation context), so "plural =
   late" needs the finer statement — the *singular-corpus* concept and the
   plural coexist for centuries, in different registers: enumerations of
   lore keep the singular (Mahābhāṣya, Arthaśāstra, Yājñ 1.3/1.45, Amara),
   ritual recitation lists go plural early (Manu, Yājñ 1.101).
2. **The pañcalakṣaṇa definition bridges the two**: Amarakośa's singular
   definition is the same verse tradition that first appears inside the
   corpus in PPL Textgruppe IIB and Matsya 53 — the definition fixes the
   *content* of "the purāṇa" as exactly the PPL material (sarga,
   pratisarga, vaṃśa, manvantara, vaṃśānucarita).
3. **The Vāyu-prokta attribution is continuous**: MBh 3 ("vāyuproktam
   anusmṛtya purāṇam") → Bḍ colophons ("brahmāṇḍe mahāpurāṇe vāyuprokte")
   → Rājaśekhara and Vācaspati still citing "vāyuproktam" c. 900–950.
   The one purāṇa that dated outside witnesses name across a millennium is
   precisely the Vāyu-attributed corpus whose oldest stratum the drift
   axis isolates.
4. Kāvya's silence (Aśvaghoṣa, Kālidāsa hits all non-generic) is a useful
   negative: purāṇa-citation is a śāstra/smṛti habit, not a kāvya one —
   which also matches the Rāmāyaṇa's total silence versus the MBh frame's
   fluency.
